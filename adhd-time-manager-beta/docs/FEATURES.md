## צריך מפתח או חשבון כדי לעבוד במלואו

| יכולת | מה צריך | מה קורה בלי זה | נבדק |
|---|---|---|---|
| הצעות AI ב-Snooze (Claude) | `ANTHROPIC_API_KEY` | הצעות בסיסיות מכללים, עם הודעה גלויה "מצב בסיסי" | ✓ עם ספק מדומה. לא נבדק מול ה-API האמיתי |
| מייל אמיתי | SMTP (למשל Gmail עם סיסמת אפליקציה) | המיילים נשמרים כקבצים ב-`instance/outbox`, והאתר אומר זאת | ✓ שמירה לקבצים. שליחת SMTP אמיתית לא נבדקה |
| Google Calendar | OAuth Client ID ו-Secret מ-Google Cloud | כתוב "לא הוגדר". היומן הפנימי עובד | ✓ מול שרת Google מדומה. לא נבדק מול Google האמיתי |
| סיכום יומי כשהאתר כבוי | Task Scheduler או cron | נשלח רק כשהשרת רץ | ✓ הפקודה `send-daily` |

## לא נכלל בגרסה הזו

- כניסה עם Google (Sign in with Google). ההתחברות היא במייל וסיסמה.
- כתיבה ל-Google Calendar (יצירת אירועים). רק קריאה.
- התראות דחיפה (Push) לדפדפן או לטלפון. בלי JavaScript אין דרך לעשות זאת, וזה גם תואם ל"התראות שקטות".
- הגופנים נטענים מ-Google Fonts. אפשר להעביר אותם לתיקייה `static/` בעתיד.
