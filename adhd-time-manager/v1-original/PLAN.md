# תוכנית עבודה: TimeFlow (פרויקט גמר 2)

הבסיס: שלד Pretech מ-`FlaskWebApp.zip`. כל התוכן שלי נמצא בדף `/zehava`, ושאר הדפים בשלד נשארים כמו שהם.

העיצוב: לפי שלוש ההדמיות של TimeFlow. רקע חי בשכבות (הר, ערפל, כדור פורח), כרטיסי זכוכית, ושביל התקדמות עם אבני דרך עד הפסגה. הפלטה: Sky blue `#8DB9DC`, Mist `#DCEAF4`, Sunset `#F4D7C1`, Forest `#456B68`, Cloud `#FFFFFF`.

## מבנה התיקייה

```
adhd-time-manager/
├── app.py                  ← השלד של Pretech + הנתיבים של /zehava (Python בלבד)
├── requirements.txt        ← flask, tzdata (שעון ישראל ב-Windows)
├── mail_config.example.json ← דוגמה להגדרות המייל (העותק האמיתי, mail_config.json, לא עולה לגיט)
├── .gitignore
├── templates/zehava/
│   ├── base.html           ← מבנה משותף: הרקע החי, הערפל והכדור הפורח
│   ├── macros.html         ← האייקונים, משותפים לכל הדפים
│   ├── login.html          ← כניסה עם שם משתמש
│   ├── index.html          ← הלוח: Navbar, סרגל צד, וכל הכרטיסים
│   ├── focus.html          ← מצב מיקוד: משימה אחת וטיימר
│   ├── sounds.html         ← Soundscape: 4 מרחבי צליל
│   └── email.html          ← הסיכום היומי שנשלח ל-Gmail
└── static/
    ├── css/zehava.css      ← כל העיצוב, בקובץ נפרד
    ├── img/
    │   ├── sky-mountain.jpg  ← ההר והשביל (בלי הכדור והטקסט)
    │   └── balloon.png       ← הכדור הפורח, שכבה נפרדת שזזה
    └── sounds/             ← deep, calm, study, reading (ogg + mp3), נוצרו בקוד
```

**הכלל:** לוגיקה ב-`app.py`, מבנה ב-`templates`, עיצוב ב-`static/css`. בלי JavaScript.
הטיימר סופר לאחור ב-CSS בלבד, והדף מתרענן לבד (meta refresh) בדיוק כשהזמן נגמר.

## הגדרת המייל (פעם אחת)

1. בחשבון Google: אבטחה ← אימות דו-שלבי חייב להיות פעיל.
2. נכנסים ל-https://myaccount.google.com/apppasswords, יוצרים סיסמה בשם TimeFlow ומעתיקים את 16 האותיות.
3. בתיקיית הפרויקט מעתיקים את `mail_config.example.json` לקובץ חדש בשם `mail_config.json` וממלאים: הכתובת, הסיסמה, ובאיזו שעה לשלוח (`daily_at`).
4. מפעילים מחדש את `python app.py`. הכפתור "שליחת הסיכום ל-Gmail" נהיה פעיל, והסיכום נשלח כל יום בשעה שנבחרה, כל עוד השרת פועל.

## הנחיות סגנון ADHD

- הפעולה הבאה תמיד ראשונה וברורה.
- מעט משימות על המסך בכל רגע, עם סינון לפי קטגוריה.
- ניצחונות גלויים: משימה שבוצעה מדליקה נקודה בשביל.
- זמנים מדויקים ולא מעורפלים (שעון ישראל).
- תנועה רגועה בלבד, ואפשר לעצור אותה בכפתור.
- בלי רצפים, בלי עונשים: יציאה ממצב מיקוד לא מוחקת התקדמות.
- הצלילים הם הצעות ולא טיפול. המשתמשת מסמנת מה עזר לה.
