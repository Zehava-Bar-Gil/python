# פרטיות ושמירת נתונים

המסמך הזה מתאר מה TimeFlow שומר, איפה, כמה זמן ומה אפשר למחוק. אותו תוכן, בקיצור, מופיע באתר בדף **פרטיות** (`/zehava/privacy`), שפתוח גם בלי התחברות.

## מה נשמר

| נתון | למה | מקור |
|---|---|---|
| שם, מייל, hash של הסיסמה (scrypt) | חשבון והתחברות | הרשמה |
| משימות, צעדים, פתקים, מחשבות ב-Snooze | התוכן של האתר | מה שהמשתמשת כתבה |
| סשנים של טיימר (מתוכנן, בפועל, השהיות) | הטיימר, הסיכום והמסע | נמדד |
| נקודות המסע | הכדור הפורח | נמדד |
| Daily Pulse (דירוג וסיבות) | תובנות, אם הלמידה פעילה | דיווח עצמי |
| משוב על תובנות וצלילים | לא להציע שוב מה שנדחה | בחירה של המשתמשת |
| הגדרות והסכמות (כולל מתי ניתנה הסכמה ללמידה) | התאמת האתר | הגדרות |
| יומן בקשות AI: סוג, ספק, סטטוס ושעה. **בלי הטקסט** | הגבלת שימוש | נמדד |
| יומן מיילים: סוג, סטטוס ושעה. **בלי התוכן** | מניעת שליחה כפולה | נמדד |
| ניסיונות התחברות: מייל, IP, הצלחה ושעה | הגנה מניחוש סיסמה | נמדד |
| אסימוני Google ואירועים (שם ושעות בלבד) | רק אם חיברו את היומן | Google |

**לא נשמר:** סיסמאות בטקסט גלוי, מפתח ה-API של Claude אצל המשתמשת, תוכן הבקשות ל-AI ביומנים, ניחוש של מצב רגשי או בריאותי.

## איפה

הכול במסד SQLite אחד בשרת שמריץ את האתר (`instance/timeflow.db`). התיקייה `instance/` לא עולה לגיט.
סיסמאות ותוכן מיילים לא נכתבים ליומני השרת. ביומן נרשמים רק סוגי שגיאות.

## מה יוצא החוצה, ומתי

| לאן | מה | מתי |
|---|---|---|
| Claude (Anthropic) | הטקסט ב-Snooze, אחרי הסתרת מייל וטלפון. בלי שם ובלי מייל של המשתמשת | רק בלחיצה על "לקבל הצעה", רק אם AI פעיל בהגדרות ויש מפתח |

| Google Fonts | בקשה לגופנים (כמו כל אתר שמשתמש בהם) | בכל טעינת דף |

## כמה זמן נשמר

| נתון | משך |
|---|---|
| כל נתוני החשבון | כל עוד החשבון קיים |
| ניסיונות התחברות | נמחקים אוטומטית אחרי 30 יום |
| קישור לאימות מייל | תקף יומיים |
| קישור לאיפוס סיסמה | תקף שעה, ופעם אחת בלבד |
| קישור למשוב מהמייל | תקף 3 ימים |
| התחברות (session) | 14 יום |
| גיבויים (`instance/backups`) | עד שמי שמריץ את השרת מוחקת אותם. **גיבוי ישן יכול להכיל נתונים של חשבון שנמחק**, ולכן כדאי למחוק גיבויים ישנים |

## מה המשתמשת יכולה לעשות (הגדרות ← פרטיות ונתונים)

- **להוריד את כל הנתונים** כקובץ JSON (בלי ה-hash של הסיסמה ובלי אסימוני Google).
- **לכבות את הלמידה האישית**, ו**למחוק את נתוני הלמידה** (משוב יומי, תובנות, משוב על צלילים). המשימות והסשנים נשארים.
- **לכבות את ה-AI** ב-Snooze. ההצעות הבסיסיות ממשיכות לעבוד.
- **לנתק את Google Calendar**: האסימון והאירועים נמחקים, וההרשאה מבוטלת אצל Google.
- **להפסיק את הסיכום היומי**, בהגדרות או בקישור שבכל מייל.
- **למחוק את החשבון**: עם סיסמה ואישור. Google מנותק, וכל הנתונים נמחקים (`ON DELETE CASCADE`).

## בדיקות שמוודאות את זה

`tests/test_isolation.py` בודק שמשתמשת אחת לא רואה ולא משנה שום דבר של אחרת, ושהייצוא כולל רק את הנתונים שלה.
`tests/test_auth.py` בודק מחיקת חשבון מלאה וניקוי ניסיונות התחברות ישנים.
`tests/test_ai.py` בודק שמייל וטלפון מוסתרים לפני השליחה, ושהמפתח לא מופיע באף דף.
